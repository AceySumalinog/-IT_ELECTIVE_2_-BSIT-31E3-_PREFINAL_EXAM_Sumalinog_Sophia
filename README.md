## ⚔️ PROJECT DESCRIPTION

MVC EXAM HUNTER is an ASP.NET Core MVC application designed to display and answer the 20 questions included in the IT Elective 2 Pre-Final Examination.

The application uses a **Manhwa Level-Up System** theme where the player can view their level, rank, experience, and quest progress while completing the examination.

---

## 🎯 FEATURES

- Player Status System
- Level and Rank System
- Experience (EXP) System
- Quest Progress Tracking
- 20 Examination Questions
- Multiple Choice Answers
- Correct Answer Highlighting
- Purple Glow Correct Answer Effect
- Quest Navigation
- Exam Completion Status
- Local JSON Exam Progress
- Responsive Manhwa-inspired Interface
